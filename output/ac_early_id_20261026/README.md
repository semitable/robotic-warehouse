## 방법

- `stream_eval.py`: checkpoint 0.256/0.512/0.768/1.0M가 각 구간을 대표하도록 구간 길이만큼(구간당 약 25만 step) 확률 마스킹 정책으로 재생. 데이터당 약 100만 env step(6 agent).

- `audit.py`: 성분 × 특징 묶음 × 경험 구간별 조건부 평균. team_gap, 10개 3+3 분할 중 실제 팀 순위, agent 쌍 AUROC.
- `summarize.py`: 곡선 표.
